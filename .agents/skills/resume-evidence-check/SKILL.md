# 目标

在投递前找出不可证明或容易误导的简历表述，并给出可安全替换的版本。

# 必要输入

- 待审核简历；
- 主简历、项目材料或用户确认的事实来源。

# 执行步骤

1. 按项目、职责、技术、规模、指标和结果拆分每条陈述。
2. 为每条标记证据：直接来源、用户确认、合理改写、无证据或冲突。
3. 特别检查 AI Agent 术语是否被夸大：Agent、multi-agent、MCP、RAG、生产级、自动化、评测和规模。
4. 检查数字、时间、客户、职位级别和因果关系是否可追溯。
5. 对无证据陈述给出删除、降级措辞或待确认问题，不替用户补事实。
6. 输出通过、需修改或阻断结论。

# 约束

- “听起来合理”不是证据。
- 不因 JD 要求而放宽事实标准。
- 不删除与岗位不匹配但真实的重要限制，改为明确风险。

# 输出格式

- 通过的陈述
- 需要修改的陈述：原文、问题、来源、建议改写
- 阻断项：无证据或相互冲突的内容
- 最终结论与投递前待确认项
