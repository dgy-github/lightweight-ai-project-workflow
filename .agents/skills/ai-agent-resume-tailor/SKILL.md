# 目标

在不改变事实的前提下，生成一版与目标 AI Agent 岗位相关度更高、可被人工验收的简历。

# 必要输入

- 主简历或经历事实库；
- 目标职位描述；
- 可选：语言、页数、地区和格式要求。

# 执行步骤

1. 先调用 `job-description-analyzer`，获得要求排序和匹配矩阵。
2. 只从主简历提取有证据的项目、职责、技术、规模、结果和时间。
3. 将经历按“问题 → Agent 工作流/工具 → 实现 → 评测或可靠性 → 业务结果”重组。
4. 优先呈现工具调用、MCP、RAG、状态管理、护栏、人工确认、可观测性、成本/延迟等真实内容。
5. 对缺少指标的经历给出补证问题，不估算数字，不把愿望写成成就。
6. 生成定制版简历、修改对照和未覆盖要求清单。
7. 最后调用 `resume-evidence-check` 检查每一条陈述。

# 约束

- 关键词只能重组表达，不能新增技术、职责、指标、客户或项目。
- 不把“使用过 LLM”升级成“设计生产级 Agent”。
- 保留主简历中的时间线和事实边界；不隐藏明显不匹配。

# 输出格式

- 定制版简历
- 关键修改对照
- JD 要求覆盖矩阵
- 需要用户确认或补证的内容
- 未覆盖要求与申请风险
