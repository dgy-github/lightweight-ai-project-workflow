# 目标

把一份职位描述转换为可核对的岗位画像、匹配矩阵和申请建议。

# 必要输入

- 完整职位描述或可访问的岗位链接；
- 主简历或经历事实库（可选，缺少时只做岗位分析）。

# 执行步骤

1. 读取完整 JD，区分硬性要求、优先要求、职责、产出、工具和软技能。
2. 针对 AI Agent 岗位单独识别 Agent 架构、工具调用、RAG、评测、观测、护栏、MCP、部署和成本延迟要求。
3. 标记每项要求的证据强度：明确要求、合理推断或无法判断。
4. 与主简历逐项匹配为“已证实、部分匹配、缺口、不可判断”，不得从关键词相似直接判定具备能力。
5. 输出岗位优先级、需要补充的问题和是否进入简历定制。

# 约束

- 不把公司宣传语当作岗位硬要求。
- 不编造岗位薪资、技术栈、级别或面试流程。
- 区分“做过”和“了解”，区分 Agent 项目与普通 LLM 调用。

# 输出格式

- 岗位摘要与职责
- AI Agent 能力矩阵
- 证据与匹配状态
- 风险、未知项和补充问题
- 申请建议：优先 / 谨慎 / 不建议
