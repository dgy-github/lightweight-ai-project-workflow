# 目标

把已核验的岗位与简历整理成可人工确认的投递包。

# 必要输入

- 职位描述和公司信息；
- 事实核验通过的定制简历；
- 用户希望强调的方向、城市、薪资和投递渠道。

# 执行步骤

1. 确认岗位分析结论、简历版本和事实核验状态；未通过时停止生成正式投递文本。
2. 提取 2～3 个与岗位最相关的真实证据，生成短版申请说明和打招呼草稿。
3. 根据渠道限制生成对应长度和语气；不群发、不制造夸张承诺。
4. 生成投递记录：公司、岗位、链接、简历版本、时间、状态、下一步和风险。
5. 列出提交前检查：岗位仍有效、公司和地点正确、附件正确、联系方式正确、内容已人工阅读。
6. 在最终提交或发送前停住，等待用户明确确认；只保存草稿，不执行外部提交。

# 约束

- 不代替用户登录、上传简历、提交申请或发送消息。
- 不记录密码、验证码、Cookie 或完整个人敏感信息。
- 不把未核验的项目、指标或能力写入投递文本。

# 输出格式

- 投递摘要
- 简历附件与版本
- 申请说明 / 打招呼草稿
- 投递记录
- 提交前检查清单
- 待用户确认事项
