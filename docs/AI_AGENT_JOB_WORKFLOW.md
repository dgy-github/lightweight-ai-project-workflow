# AI Agent 求职流程

## 使用目标

这组 Skill 用于提高岗位判断、简历改写和投递准备的一致性，不承诺获得面试，也不通过
编造经历提高表面匹配度。

## 标准流程

1. 使用 `job-description-analyzer` 分析完整 JD，判断岗位要求和真实匹配度。
2. 确认值得申请后，使用 `ai-agent-resume-tailor` 从主简历生成定制版本。
3. 使用 `resume-evidence-check` 逐条核验技术、职责、指标、时间和成果。
4. 只有核验通过后，使用 `job-application-draft` 生成投递文本和记录。
5. 使用者检查最终简历、公司、岗位和联系方式后，自行提交或明确授权具体投递操作。

## AI Agent 岗位重点能力

根据 JD 实际内容选择，不要求一份简历覆盖全部项目：

- Agent 工作流、任务分解和状态管理；
- Tool calling、MCP 和外部系统集成；
- RAG、上下文管理和事实 grounding；
- Agent 评测、可观测性、失败恢复和人工确认；
- 护栏、权限、隐私和提示注入防护；
- 成本、延迟、吞吐和可靠性优化；
- 多 Agent 协调和生产部署；
- 与具体业务结果相连的交付证据。

关键词出现不代表具备能力。只有主简历、项目资料或用户明确确认能够证明的内容，才可以
进入定制简历。

## 最低验收标准

- JD 的重要要求均标明来源和匹配状态；
- 定制简历每条新增或强化表述都能追溯到事实来源；
- 无来源指标、技术和项目已经删除或降级；
- 未覆盖要求和申请风险明确可见；
- 投递草稿未自动发送，最终提交由使用者确认。

## 备注说明

- 主简历应保留完整事实，定制版本只调整顺序、重点和准确表达。
- 招聘网站规则和岗位信息可能变化，投递前需要重新检查岗位是否有效。
- 简历、联系方式和工作经历属于个人信息，不上传到未经确认的第三方服务。
